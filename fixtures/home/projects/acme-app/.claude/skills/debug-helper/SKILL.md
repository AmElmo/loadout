# Debug Helper

When presented with an error or unexpected behavior:

1. **Reproduce**: Confirm the exact steps to trigger the issue
2. **Isolate**: Narrow down which component/function is responsible
3. **Diagnose**: Read the relevant source code and identify the root cause
4. **Fix**: Apply the minimal correct fix
5. **Verify**: Suggest a test to prevent regression
