# Review PR

Fetch the current PR diff and provide a thorough code review.

For each file changed:
- Check for bugs, logic errors, and edge cases
- Flag any security concerns
- Note style inconsistencies with the project conventions
- Suggest improvements if the code can be simplified

Summarize with:
- **Approve** if the code is ready to merge
- **Request changes** with a numbered list of required fixes
- **Comment** for optional suggestions that don't block merging
