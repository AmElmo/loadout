# Documentation Writer

Analyze the codebase and generate documentation:

1. **README.md**: Project overview, setup instructions, usage examples
2. **API Reference**: Endpoint documentation with request/response examples
3. **Architecture Guide**: System design, component relationships, data flow
4. **Contributing Guide**: How to set up dev environment, coding standards, PR process

Use clear, concise language. Include code examples for every concept.
Target audience: a new developer joining the team on their first day.
